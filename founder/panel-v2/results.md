## What would flip a no

- Good App Store and Reddit reviews saying the Start Kit widget really helps people start tasks, and the Start Kit sold alone for $1.99 or less.
- If the lock-screen widget with one-tap start was a standalone $0.99 and it clearly helped me actually start tasks, I might try it.
- If I'm still using it every day after a month and the widget is the one thing that actually gets me to start, I might pay the $1.99 for just that pack.
- If the lock-screen widget and one-tap start were sold alone for about $2, and I'd already used the app daily for a month, I might buy that one.
- If I was still opening it daily after week 3 and the lock-screen widget made starting tasks easier, I might buy the Start Kit for $1.99.
- If the widget on the lock screen was a separate $0.99 thing, I might try just that.
- If I was still opening it daily after a month and the widget on my lock screen actually made me start stuff, I might get the Start Kit for $1.99.
- If I was still using it daily after the 7 days and the lock-screen widget made starting tasks actually easier, I might get just the $1.99 Start Kit.
- If the lock-screen widget was sold alone for about a dollar, I might try it, since a one-tap start is the only thing that would really help me.

Buyers say they would buy **1.0 times** in the first month on average.
